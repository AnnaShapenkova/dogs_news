## Порядок переключения

Пользователь запросил подготовку push T18 для сбора публикаций. В корне подготовлен COMMIT-T18.bat: запуск пользователем создаёт отдельный коммит T18 и обычный push origin/main. Проверяются точный origin dogs_news, main, пустой индекс и совместимость удалённой истории. Файлы добавляются явно, включая specs/PRODUCT_V2.md как зафиксированную продуктовую рамку с предложениями дальнейших задач. evaluation/, рабочая .env, .tools, BAT и логи не добавляются. .env.example содержит только пустые ключи/пример подключения. При ошибке файл останавливается без force push/merge/reset. Лог COMMIT-T18.log. Тесты, платные вызовы, resume и развёртывание файл не запускает. Агент BAT не запускал; успех отправки требуется подтвердить логом.

1. Остановить Worker перед изменением переменных/обновлением. Сохранить существующую БД и убедиться в возможности восстановления backup; не пересоздавать том. Не удалять runs или старые публикации.
2. После отдельно согласованных коммита/push обновить существующие службы из той же версии репозитория. Переключение выполняет пользователь, агент его не запускает.
3. В переменных Worker удалить OPENROUTER_API_KEY и старую общую MODEL. Добавить AITUNNEL_API_KEY из кабинета AITunnel, DRAFT_MODEL=glm-4.7, REVIEW_MODEL=claude-haiku-5.5. Ключ в чат/логи/Git не копировать. Старый ключ не является запасным; он не включает Worker.
4. Обновлённый Compose передаёт новый ключ и две модели. При другой ручной настройке служб передать те же переменные Worker. Endpoint фиксирован в коде; дополнительных API URL не требуется. Collector и bot не нуждаются в модельном ключе.
5. До включения цикла проверить версию и конфигурацию командой ниже. Команда не обращается к модели, БД или Telegram. Если Worker уже работает, он может сразу расходовать бюджет и публиковать: простой рестарт не является предпросмотром.
6. Проверить сохранённую платёжную паузу: `python -m worker.provider`. Это чтение БД без модели/рассылки. Смена сервиса сама её не снимает. `python -m worker.provider --resume` — отдельное явное действие после проверки средств; после resume работающий Worker может немедленно начать обработку. Агент не выполняет resume.
7. Пользователь включает Worker, когда готов к реальным расходам/автопубликациям. История текущих UTC-суток сохраняется: 8 публикаций / 60 попыток / 80 вызовов — общий предел GLM и Haiku вместе, без обнуления потраченного.

## Проверка без вывода ключа

В обновлённом контейнере /app (не запускает worker.main):

```sh
python -c "from worker.editorial import RULES_VERSION; from worker.main import PROMPT_VERSION; from worker.config import configured_models, api_key; from worker.budget import MAX_PUBLICATIONS, MAX_ATTEMPTS, MAX_MODEL_CALLS; print(RULES_VERSION, PROMPT_VERSION, configured_models(), MAX_PUBLICATIONS, MAX_ATTEMPTS, MAX_MODEL_CALLS, 'key_configured='+str(bool(api_key())))"
```

Ожидается dogs-pilot-v8 dogs-v8, provider=aitunnel, draft_model=glm-4.7, review_model=claude-haiku-5.5, 8 60 80, key_configured=True. Последнее подтверждает только наличие непустого значения, не валидность ключа/оплату/права модели. Не выводить окружение целиком, DATABASE_URL, Authorization или сырой ответ с ошибкой.

## Приёмка

- /status показывает сохранённый бюджет и паузу без ложного указания нового сбоя OpenRouter. Новая 402-пауза AITunnel останавливает дальнейшие попытки.
- Новые закрытые runs worker_model_call имеют phase=draft/model=glm-4.7 и phase=review/model=claude-haiku-5.5, provider=aitunnel. Это один счётчик вызовов. Не публиковать внутренний аудит в чат читателей.
- Получить новую карточку и оценить смысл/язык, проверить оригинал. Отрицательный review удерживает текст. Доступность моделей и совместимость JSON-параметров с рабочим ключом подтверждаются только этим живым этапом, не изолированными тестами.
- Старые опубликованные материалы доступны. Известный совместимый v7 draft проходит новое review Haiku без повторного draft; старое происхождение генератора сохраняется. Несовместимые checkpoint удерживаются, неопределённый оплаченный ответ не повторяется автоматически.
- Не перепоставлять все held/error. Сохранённая очередь collected обрабатывается автоматически в пределах бюджета; разбор выбранных прежних ошибок — отдельно по ID через существующий preview requeue.
- Если появились 400/401/403/429/5xx или обрезанные ответы, прислать безопасный код/причину из статуса. Не менять модели или параметры вслепую. Безопасный отказ не означает пройденную живую приёмку.

Подробность текста в T18 не увеличена; редакционная настройка по реальным примерам остаётся следующей отдельной задачей. Переключение сервиса не доказывает исчезновения ветеринарного уклона.

## Откат

Остановить Worker, сохранить данные, новые payload/checkpoint и журнал. Старый Worker не запускать поверх новых незавершённых checkpoint без проверки совместимости. Не удалять историю/строки, не сбрасывать бюджет/паузу. Автоматического возврата к OpenRouter нет. Reader продолжает читать прежние публикации, SQL-сужения/пересоздания тома не требуется.

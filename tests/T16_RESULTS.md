# T16 — результаты и границы проверки

Реализован утверждённый вариант B и кремовая Mini App. Платные вызовы, рабочая БД, рассылка и развёртывание агентом не выполнялись. Редакционная приёмка нового реального текста остаётся за пользователем; старый клинический материал не изменён.

## Автоматические проверки

- Python 3.12.10: `python -m unittest discover -s tests -p 'test_*.py' -q` — 158 тестов: 101 пройден, 57 PostgreSQL-тестов пропущены (TEST_DATABASE_URL не задан).
- `node tests/test_mini_app.js` — пустое состояние и статья/заметка с источниками, ограничениями и экранированием пройдены.
- `node tests/test_mini_app_t16.js` — светлая тема, собачьи акценты, тёмная тема Telegram с согласованными header/background/bottom/MainButton, отсутствующие API, возврат и фильтры, контраст заданных текстовых пар ≥4.5:1 пройдены. Это VM со stub DOM, не реальный Telegram/рендерер.

## Критерии SPEC

| Критерий | Результат |

| 1. Ложное trained | Воспроизведена ошибка старого фильтра; shared-фильтр больше не трактует trained veterinarians как обучение собак. Синтетический клинический пример по мотивам LISTEN удерживается до модельного вызова. Полный live-прогон настоящего LISTEN новым Worker не выполнялся. |
| 2–3. Понятный предмет | Проверены обучение собак при авторах-ветеринарах, исследование поведения с использованием machine learning, отдых/благополучие в ветеринарном журнале. Это примеры политики, не оценка научной истинности. |
| 4. Строгий fit | Clinical/specialist/unclear останавливаются после одного draft без review/каскада; повреждённая оболочка и skip с article-объектом не проходят; вопрос и точный фрагмент обязательны. |
| 5. Независимая аудитория и язык | owner_relevant=false — конечный отказ; plain_language=false подходящего сюжета может привести к новой проверенной ступени, сохраняя вопрос/fit. Строки вместо bool не проходят. |
| 6. Бюджет/приватность/история | Прежние unit-проверки бюджета и allowlist проекции проходят. SQL-проверки fit, отказов, продолжения и миграции T15 написаны, но пропущены. Fit/owner_question не добавлены в публичные payload. |
| 7. Изоляция | Все внешние вызовы подменены; 57 реальных PostgreSQL-сценариев не выполнены. |
| 8. Реальная публикация нужной аудитории | Не выполнено. Нужно обновление пользователя и оценка нового текста. |
| 9–10. Светлый UI и эмодзи | Контракты HTML/JS, фиксированные цвета Telegram, программный выбор эмодзи, наличие текстовых подписей проверены. Реальный Telegram недоступен. |
| 11. Поведение/контраст | Пройдены JS-сценарии и расчёт контраста заданных цветовых пар. Реальное взаимодействие/фокус/анимация в браузере не проверены. |

Проверка рендера 320/390/430 px и отсутствия горизонтального скролла не выполнена: инструмент браузера не подключился, headless Edge завершился ошибкой GPU process launch. ## Локальные макеты и блокировка визуальной проверки

В `.tools/t16-preview/` подготовлены feed.html, article.html, empty.html, how.html из реального шаблона/CSS с явно помеченными синтетическими данными. Рабочая БД и Telegram SDK не подключаются. Папка игнорируется Git и остаётся локальной; содержимое не является реальными публикациями редакции.

Computer Use вернул отсутствие доступных браузеров/native pipe. Штатный установленный Edge с отдельным headless-профилем завершился ошибкой GPU process launch; защитные ограничения не отключались. Скриншотов нет. Пользователь может открыть макеты обычным браузером; реальную адаптивность и Telegram нужно проверить после обновления.

## Переход checkpoint и ограничения

- Новые версии dogs-pilot-v6 / dogs-v6. Для известного сохранённого checkpoint T15 создаётся новая оценка аудитории; исходная история сохраняется в migration_history и старых runs. Hash должен совпадать. Старое одобрение не считается прошедшим новую проверку аудитории.
- При неопределённом старом generating/reviewing с зарезервированным вызовом — uncertain_stage, автоматического повторения нет. SQL-сценарии сохранности/возобновления написаны, но пропущены.
- Первый полный draft-ответ: editorial_fit + article. При length без сохранённого fit следующий короткий формат всё ещё обязан получить эту оболочку; в обход fit не пройти. Дополнительного вызова на классификацию нет; максимальный путь по-прежнему 6 вызовов, обычный 2, явный skip расходует 1.
- Модель может ошибиться и при двух проверках. Типизированный fit и контрольные примеры уменьшают лазейки, но не доказывают редакционное качество на реальном потоке. Требуется показ новых текстов пользователю.
- Старый опубликованный материал о сердце не удалялся и не переписывался. Для его изменения нужна отдельная согласованная операция с историей.

Инструкция: [Coolify T16](../specs/T16-owner-editorial-fit/COOLIFY.md). Разрешение на push T16 получено, но агент сам не может записывать `.git`; подготовлен локальный файл отправки от пользователя. До его успешного выполнения коммит/push не считать выполненными.

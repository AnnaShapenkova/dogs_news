# T12 — результаты и ограничения

Код реализован по утверждённой SPEC; операционная цель ещё НЕ достигнута: реальной публикации и доставки на Coolify агент не наблюдал. Доступ к рабочей БД и платной модели не использовался.

## Выполнено локально

Python 3.12.10, существующий psycopg, `python -m unittest discover -s tests -p 'test_*.py' -v`: 89 тестов, 53 пройдены, 36 PostgreSQL-тестов пропущены (TEST_DATABASE_URL не задан). `node tests/test_mini_app.js`: оба сценария пройдены — пустая лента и публикация с темой, источником, ограничениями и экранированием.

Модельные и сетевые ответы подменены; источники синтетические. Эти тесты проверяют механизм, не научную истинность и не качество модели на реальном материале. Модуль worker/budget.py — общий код чтения бюджета, не отдельный сервис. Модуль worker/requeue.py — явная CLI-команда, не фоновый процесс.

## Соответствие приёмке SPEC

| Критерий | Результат |
| --- | --- |
| 1. Контекст риска и запреты | Пройдены локальные проверки чувствительных сигналов, опасных предписаний, отказа рецензента, неопределённого риска, доказательств и инъекций. Реальное качество рецензента не оценено. |
| 2. Ответы провайдера | Чистый/fenced JSON принимается для дальнейшей проверки; проза, пустота, усечение, неправильная структура, HTTP/таймаут проверены. Приём JSON не равен допуску. |
| 3. Полный путь | JS и изолированные Python-проверки пройдены. PostgreSQL → Mini App → подменённый Telegram написан, но пропущен. Внешние ключи/аудиты не передаются публичной проекции. |
| 4. Бюджет и повтор | Локально проверены отображение лимитов/UTC, отсутствие пустых прогонов при лимите, ограничения ID. PostgreSQL-проверки сохранения истории, идемпотентности, отказа всей пачки, дублей и учёта бюджета написаны, но пропущены. |
| 5. Реальная публикация | Не выполнено: требуется обновление и проверка на стенде пользователем. При 0 публикаций задачу нельзя считать полностью принятой. |

## Существенные ограничения

- Суточные лимиты сохраняются. Старые попытки текущих суток продолжают учитываться; очередь ждёт следующего окна 00:00 UTC, если бюджет исчерпан.
- 2400 max_tokens, модель и число платных вызовов не увеличены. Если причина прежних ошибок — усечение, теперь появится точный код model_truncated; его устранение может потребовать отдельного изменения лимита после подтверждения причины. Успешный запрос в Activity не доказывает валидный content.
- Рецензент работает той же моделью; структурные проверки не гарантируют семантическую достоверность. Предписания блокирует код и рецензент, но перечисление слов никогда не покрывает все опасные формулировки.
- Повтор доступен для подходящих сохранённых Europe PMC snapshots со старой версией правил. Популярные статьи без однозначного первоисточника, публикации сомнительного статуса, дубли, уже опубликованные и уже обработанные текущими правилами не перепоставляются этой командой.
- История повтора хранит прежний editorial_result в runs.note. Сырые ответы провайдера не сохраняются. Подробности четырёх прежних ошибок восстановить нельзя.
- Существующее ограничение sent_at на находку, а не на отдельного подписчика, не менялось в T12.

Инструкция для пользователя: [запуск T12 на стенде](../specs/T12-editorial-policy/COOLIFY.md). Коммит/push и развёртывание ещё не выполнены агентом.

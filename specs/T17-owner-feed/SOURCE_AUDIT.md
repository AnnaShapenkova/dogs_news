# T17: проверка источников, 16 ноября 2026

Это результаты ограниченных HTTP GET и чтения официальных страниц. Адаптеры Collector ещё не реализованы. Рабочая БД, модели, Telegram и Coolify не использовались. HTTP 200 не равен редакционному допуску, robots.txt не является лицензией. Конкретные сетевые ответы могут измениться после этой проверки.

### РКФ: условия и ограничения способа сбора

[Официальные правила](https://rkf.org.ru/upload/documents/rules/rules_site.pdf), п. 2.1: допускают короткие аннотации для обзоров, с атрибуцией по п. 3.1; полный материал не перепубликуется. Пп. 3.1–3.2 требуют источник/автора/дату и сохранение смысла. Использовать краткое содержание, не переносить весь текст/изображения. Подпись источника по правилам: «Источник: Официальный сайт Российской Кинологической Федерации RKF.org.ru».

robots.txt доступен, каталог и проверенные статьи не запрещены. При этом */feed/ и */rss/ запрещены: RSS РКФ не использовать, даже несмотря на технический HTTP 200 при первоначальной параллельной пробе. Последующие проверки шли через разрешённый HTML-каталог. /wp-content/uploads/ разрешён отдельным Allow, однако PDF-разбор для продуктовых источников T17 не нужен.

### «Питомцы»: не подключать общую ленту

У проверенных страниц/футера указана обязательная активная ссылка на использованный материал. Используем краткую аннотацию с автором, издателем и прямой ссылкой; изображения и весь материал не перепечатываем. [Раздел воспитания](https://vetandlife.ru/pets/vospitanie/) и [Зооменю](https://vetandlife.ru/pets/zoo-menu/) содержат ссылки на свои RSS.

robots.txt не запрещает указанные пути; /wp-json/ и административные пути запрещены, использовать их нельзя. Общая /feed/ технически работает, но смешивает сельское хозяйство, англоязычные дубликаты, коммерцию и медицину. От неё отказались. Официальная /rss/news.xml имеет другую XML-структуру (link не прочитался стандартным findtext), поэтому не подменять ею выбранные обычные RSS без адаптера.

Даже узкие RSS содержат кошек, /pet-business/, законодательство, медицинские материалы и рекламу. Ни название раздела, ни язык не разрешают публикацию. Нужны фильтр на собак, предмет и пригодность обычному владельцу, а также разбор основного текста. В sampled HTML есть NewsArticle, но нет articleBody; нельзя рассчитывать на текст в JSON-LD. Основной контейнер нужно закрепить fixture-тестами, меню и «Читайте также» не использовать как содержание.

### PLOS

[API и документация](https://api.plos.org/), [лицензионная политика](https://journals.plos.org/plosone/s/licenses-and-copyright). Политика предусматривает повторное использование статей с атрибуцией; лицензию конкретной статьи и исключения для чужих материалов проверять отдельно. /robots.txt API вернул 404, не 403; интерфейс API документирован, ключ/новый платный сервис не требуется. Конкретные queries/пагинацию и соблюдение правил API проверять в адаптере; не считать один успешный GET интеграционной проверкой Collector.

## Контрольные реальные страницы

Это входы для тестов и анализа, не утверждённые публикации. Научная корректность всего содержания не установлена этой проверкой.

2. [РКФ: игры](https://rkf.org.ru/poleznye-materialy-o-sobakah/igry-dlya-sobak-sbornik-poleznyh-aktivnostej-dlya-zhivotnyh-v-lyubom-vozraste/) — HTTP 200, даты JSON-LD 23.09.2026/25.09.2026. Кандидат для learning/welfare, не гарантия безопасности всех упражнений.
3. [РКФ: правила дрессировки](https://rkf.org.ru/poleznye-materialy-o-sobakah/osnovnye-pravila-dressirovki-sobak/) — отрицательный контроль: в доступном тексте встретились бросок предмета в щенка и одёргивание поводком. Не рекламировать такое руководство как безопасную технику и не удалять опасную часть из пересказа, продолжая рекомендовать исходник.
4. [«Питомцы»: ноузворк](https://vetandlife.ru/pets/vospitanie/sport-po-poisku-zapahov-kak-nouzvork-razvivaet-sobaku-i-provodnika/) — HTTP 200, автор указан, дата 16.02.2026. Учесть принадлежность экспертов к торговой сети, не переносить рекламные обещания.
5. [«Питомцы»: пищевое поведение](https://vetandlife.ru/pets/otkaz-ot-edy-lishnij-ves-i-poproshajnichestvo-razbiraem-chastye-problemy-s-pitaniem-sobak/) — HTTP 200, автор/эксперт указаны. Отрицательный контроль для автоматических рекомендаций: ответы о конкретном питомце, изменение порций/рациона, коммерческая аффилиация. Не превращать в универсальное назначение.
6. [«Питомцы»: нутриенты рационов](https://vetandlife.ru/pets/varenyj-ili-syroj-pochemu-dazhe-pravilnyj-racion-dlya-sobak-provalil-proverku-po-nutrientam/) — HTTP 200, дата 09.06.2026. Простой поиск научных href не обнаружил DOI/ссылку на журнал. Проверить весь текст в адаптере; отсутствие ссылки в этой пробе не доказывает её отсутствие вообще. Не публиковать как подтверждённый научный вывод без научного источника.
7. PLOS DOI 10.1371/journal.pone.0300889 — реально вернулся в API-пробе, дата 21.03.2024, аннотация об изменении выбора еды после социального взаимодействия. Кандидат для behavior, а не автоматически nutrition только по слову food. Проверка статуса работы ещё не выполнена.

## Пока не включать

- N+1: публичная RSS /rss вернула 200, но обычные запросы robots.txt и /about — 403. Не обходить ограничения и не утверждать пригодность полного текста. Оставить резервом до ясного способа доступа/использования.
- Dogs Trust/PDSA: страницы и руководства доступны, но ранее проверенные условия ограничивают перепубликацию. С учётом требования пользователя о содержательной карточке не включать как автоматические источники рерайта T17. Пустые ссылки выпуск не заполняют.
- Waltham: robots.txt вернул 403; не включать автоматически.
- «Наука и жизнь»: главная/robots.txt доступны, но способ и условия использования конкретных текстов в рамках этой проверки не установлены. «Элементы»: robots.txt задаёт Crawl-delay 60 для общего агента; отдельный адаптер и условия не исследованы. В T17 не добавлять.

## Что эта проверка не доказала

Не доказаны стабильность HTML, отсутствие ошибок адаптеров, доступность тех же URLs из Coolify, пять ежедневных пригодных материалов и результаты платной редакционной обработки. Смешанный поток подтверждает необходимость отбора, а не разрешение автоматически публиковать всё. Положительные fixtures и реальный выпуск должны подтвердить качество T17 после утверждения и реализации.

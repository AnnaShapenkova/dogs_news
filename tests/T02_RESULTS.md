# T02: реализация и проверка

Статус: код подготовлен по утверждённой SPEC. Полная приёмка ожидает PostgreSQL-проверок. Коммит, push, изменение БД Coolify, реальный сбор в БД и публикации агентом не выполнялись.

## Изменения

- Collector: Europe PMC + ScienceDaily RSS, явный список источников, окно 90 календарных дней UTC, предварительный тематический фильтр, максимум 15 новых вставок за проход с распределением 10+5 и перераспределением остатка.
- Исходный JSON/XML и контекст сохранения в raw_payload; доступное содержание без обрезания до 1500 символов; content_scope отличает реферат от RSS-фрагмента и неизвестных старых данных.
- Новые входы — collected, старый Worker их не выбирает. Модель, настройки OpenRouter, интерфейсы, Dockerfile, Compose и зависимости не менялись.
- Схема: два поля с ограничением; пять AI-URL отключаются, прежние данные не удаляются; новые seed не сбрасывают ручное отключение.
- init_schema теперь выполняет SQL в одной транзакции под прежней advisory lock и читает UTF-8 явно.
- Схема T01 из b75d08a сохранена тестовой фикстурой, чтобы проверять обновление существующей БД, а не только пустой старт.

## Проверки

Целевой локальный интерпретатор — переносимый Python 3.12.10, существующий psycopg[binary] 3.3.6, без новых зависимостей. Команда: `python -m unittest discover -s tests -p 'test_*.py' -v`. Последний полный запуск: **44 теста, 24 пройдены, 20 пропущены** из-за отсутствия TEST_DATABASE_URL/тестовой PostgreSQL. Skipped не считается успехом проверки БД. Пройдены 14 ReaderTests, 8 AllocationTests и 2 MessageTests из T01.

JS пустого состояния Mini App прошёл после изменений Collector: `node tests/test_mini_app.js`. Эта проверка не является настоящим Telegram-клиентом.

## Пробные чтения источников

Отдельно от тестов выполнены два ограниченных чтения без записи в БД, модели и Telegram. Europe PMC: прочитано 45 записей за три страницы, предварительный фильтр оставил 45; достигнут лимит просмотра. ScienceDaily: 60 RSS-записей, 51 вне окна, 9 вне темы; подходящих в этом снимке нет. Поэтому при аналогичном входе новый проход может состоять только из исследований, не из выдуманных популярных материалов. Живой ответ не является фикстурой и может измениться.

Дополнительная проверка смысла совпадений нашла biological behaviour в описании опухоли и machine learning в медицинской статье. Эти значения отделены от поведения/обучения собаки явным фильтром и отрицательными тестами. Повторный probe Europe PMC: 45 просмотрено, 40 кандидатов, 5 пропущены вне темы, лимит просмотра достигнут, ошибок нет. Содержательная научная оценка всех оставшихся кандидатов по-прежнему не выполнена — её предлагает T03.

На локальных портах 5432 и 55439 PostgreSQL недоступна. Прежняя попытка initdb завершалась ошибкой restricted token Windows sandbox; её ограничения не обходились. БД пользователя на Coolify агентом не проверялась. Инструкция полной проверки — tests/README.md, включая безопасный loopback-доступ отдельной тестовой БД.
